# Паттерны проектирования (лабораторная 6)

## 1. Adapter (Адаптер)
**Класс:** `FriendPluginAdapter`  
**Зачем:** плагины товарища реализуют `IFriendDataProcessor` (другие имена методов), а приложение работает с `IDataProcessingPlugin`. Адаптер переводит вызовы `EncodeBeforeSave` / `DecodeAfterLoad` в `ProcessBeforeSave` / `ProcessAfterLoad`.

## 2. Strategy (Стратегия)
**Класс:** `DataProcessingPipeline`  
**Зачем:** перед сохранением и после загрузки можно включать разные алгоритмы обработки (шифрование, плагин товарища и т.д.) без изменения кода сохранения — достаточно подставить другой набор стратегий.

## 3. Command (Команда)
**Классы:** `IMenuCommand`, `MenuCommandRegistry`, `DelegateCommand`  
**Зачем:** пункты меню инкапсулированы в объекты-команды; реестр выполняет действие по клавише. Удобно добавлять новые команды без разрастания `switch`.

## 4. Singleton (Одиночка)
**Класс:** `AppSettings`  
**Зачем:** единый экземпляр настроек (какие плагины обработки включены) доступен из любого места программы.
